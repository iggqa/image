# Xcode 开发者磁盘映像

# 为什么我们需要磁盘映像？
当你的苹果设备升级到新的操作系统版本时，你当前使用的 Xcode 版本没有与该操作系统版本相匹配的磁盘映像。这会阻止你将构建推送到设备上。

### iOS

下载 ZIP：[https://github.com/mspvirajpatel/Xcode_Developer_Disk_Images/releases](https://github.com/mspvirajpatel/Xcode_Developer_Disk_Images/releases)

下载最新版：[https://github.com/doronz88/DeveloperDiskImage](https://github.com/doronz88/DeveloperDiskImage)

# 启用开发者模式
在 iOS 设备上前往“设置”>“隐私与安全性”。向下滚动到“开发者模式”列表项并进入。要切换开发者模式，请使用“开发者模式”开关。
